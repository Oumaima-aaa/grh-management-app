<h1 align="center">🏢Gestion des Ressources Humaines</h1>

<h3 align="center">Human Resources Management System | React & Laravel</h3>

<p align="center">
  A modern web application for managing employees and human resources processes.
</p>

---

<h2>📌 About the Project:</h2>

<p>
GRH Management App is a full-stack Human Resources Management System designed
to simplify and digitalize HR operations.
</p>

<p>
The application provides different spaces for:
</p>

- 👨‍💼 Admin
- 👩‍💼 Responsable RH
- 👤 Employé
